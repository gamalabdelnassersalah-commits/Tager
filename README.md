# Tager Marketplace

منصة Tager لتجارة الجملة وجملة الجملة للمواد الغذائية في مصر.

هذا مشروع Frontend تجريبي جاهز للتجربة على React + Vite.  
الفكرة: موردين، مشترين، منتجات، فئات، سلة، لوحات تحكم، وصفحات تسجيل.

## التشغيل
```bash
npm install
npm run dev
```

## الصفحات
- الرئيسية
- المنتجات
- الفئات
- انضم كمورد
- سجل كمشتري
- لوحة المورد
- لوحة المشتري
- لوحة الإدارة
- تواصل معنا
